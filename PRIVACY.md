# 隐私说明 / Privacy

网页媒体助手不包含遥测、广告或自建服务器上传逻辑。扩展需要访问网页内容，以发现媒体元素、观察媒体请求并解析悬停目标；设置保存在 Firefox 的扩展存储中。

媒体检索结果可能包含当前页面请求的媒体网址并暂存在本地扩展存储。图片预览会按站点规则访问目标图片或页面，以解析原始图片地址。只有用户主动下载时才会调用 Firefox 下载功能。扩展不会通过旧版 Imagus 的“发送图片”服务提交图片网址。

Web Media Assistant contains no telemetry, advertising, or project-operated upload endpoint. It accesses page content to control media, observe media requests, and resolve hover targets. Settings are stored in Firefox extension storage.

Media discovery may temporarily store media URLs requested by the current page. Image preview may request a target image or page when a site resolver needs the original image URL. Firefox downloads are created only after a user action. The legacy Imagus “send image” services are not included.
